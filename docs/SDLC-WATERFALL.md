# SDLC Waterfall - Project Crowdfunding

## 1. Judul Project
Sistem Informasi Crowdfunding Donasi Online

## 2. Deskripsi Singkat Project
Project ini adalah aplikasi web untuk mengelola kampanye donasi secara online. Pengguna dapat membuat campaign, melihat detail kampanye, dan melakukan donasi. Admin dapat memantau transaksi serta perkembangan kampanye.

## 3. Penjelasan Metode SDLC Waterfall
SDLC Waterfall adalah metode pengembangan perangkat lunak yang berjalan secara berurutan dari tahap awal sampai akhir. Setiap tahap harus selesai terlebih dahulu sebelum masuk ke tahap berikutnya. Metode ini cocok untuk project yang kebutuhan dan ruang lingkupnya jelas sejak awal.

## 4. Tahapan Waterfall yang Digunakan dalam Project
- Analisis kebutuhan
- Desain sistem
- Implementasi / coding
- Pengujian / testing
- Deployment / penerapan
- Maintenance / pemeliharaan

### Analisis Kebutuhan
Pada tahap ini, tim mengumpulkan kebutuhan dari pengguna dan pemangku kepentingan. Kebutuhan yang dirangkum meliputi fitur utama seperti registrasi, login, pembuatan campaign, transaksi donasi, dan dashboard admin. Hasil tahap ini adalah dokumen kebutuhan yang jelas agar tidak ada perubahan besar di tengah proses.

### Desain Sistem
Setelah kebutuhan terkumpul, tim membuat desain sistem yang mencakup arsitektur aplikasi, alur data, dan rancangan antarmuka. Misalnya, ditentukan struktur halaman utama, halaman detail campaign, serta dashboard admin. Database dan alur penyimpanan data juga dirancang agar aplikasi mudah dikembangkan.

### Implementasi / Coding
Tahap implementasi adalah proses menulis kode berdasarkan desain. Tim membangun halaman front-end, membuat API untuk menangani data campaign dan donasi, serta menghubungkan sistem autentikasi. Semua fitur yang sudah dirancang mulai diwujudkan dalam bentuk aplikasi yang bisa dijalankan.

### Pengujian / Testing
Setelah fitur selesai, dilakukan pengujian untuk memastikan aplikasi berjalan sesuai kebutuhan. Pengujian meliputi uji fungsi login, pembuatan campaign, proses donasi, dan tampilan dashboard. Jika ditemukan bug, perbaikan dilakukan sebelum aplikasi dipublikasikan.

### Deployment / Penerapan
Pada tahap ini aplikasi dipasang di server agar dapat diakses pengguna. Konfigurasi server, domain, dan pengaturan keamanan dilakukan supaya aplikasi stabil dan siap digunakan.

### Maintenance / Pemeliharaan
Setelah aplikasi digunakan, tim melakukan pemeliharaan untuk memperbaiki bug yang muncul dan menyesuaikan kebutuhan baru. Pemeliharaan juga mencakup peningkatan performa dan keamanan agar aplikasi tetap berjalan dengan baik.

## 11. Contoh Penerapan Waterfall pada Project Perangkat Lunak
Contoh penerapan Waterfall pada project crowdfunding ini adalah: tim mulai dengan analisis kebutuhan seperti fitur donasi dan kampanye. Lalu membuat desain halaman serta struktur database. Setelah desain disetujui, tim melakukan coding secara bertahap. Setelah aplikasi selesai, dilakukan testing untuk memastikan semua fungsi berjalan. Selanjutnya aplikasi dideploy ke server. Terakhir, tim melakukan maintenance berdasarkan masukan pengguna.

## 12. Kesimpulan
Metode SDLC Waterfall membantu pengembangan project ini berjalan terstruktur dan terencana. Karena setiap tahap diselesaikan secara berurutan, tim dapat fokus pada kualitas di tiap tahap dan mengurangi risiko perubahan besar di akhir. Metode ini cocok untuk project yang kebutuhannya sudah jelas sejak awal.
